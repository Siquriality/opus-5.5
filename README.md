# Де зроблено це фото?

Застосунок пропонує можливі місця на вибраній ділянці лівого берега Києва. Ви вручну обираєте орієнтири, які бачите на фото, а програма шукає, де такі об’єкти розташовані поруч.

Проєкт створено для хакатону KSE з Python та відкритих даних.

## Як запустити

Потрібен Python. У терміналі відкрийте папку репозиторію та виконайте:

```bash
python -m venv .venv
```

Активуйте середовище. У PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

На macOS або Linux:

```bash
source .venv/bin/activate
```

Встановіть залежності та запустіть застосунок:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Відкрийте [http://localhost:8501](http://localhost:8501).

## Як користуватися

1. Виберіть щонайменше два типи орієнтирів: міст, трамвайна зупинка, церква, парк або пам’ятник.
2. Встановіть радіус від 100 до 1500 м. Початкове значення — 400 м.
3. Натисніть **«Знайти місця»**.
4. Перегляньте до трьох кандидатів на карті. Для кожного показано, які орієнтири знайшлися поруч і на якій відстані.

Оглядова карта під формою показує всі об’єкти з набору даних. Карта в результатах показує лише кандидатів поточного пошуку.

## Як працює пошук

`app.py` читає `data/places.csv` і передає дані та параметри форми у `find_places` з `search.py`. Пошук бере за опорні точки об’єкти найрідшої з вибраних категорій. Біля кожної опорної точки він шукає найближчий об’єкт кожної іншої вибраної категорії та порівнює відстань із радіусом.

Кандидати мають щонайменше два збіги. Спочатку програма сортує їх за кількістю збігів, а за однакової кількості — за меншою сумою відстаней.

Застосунок працює за орієнтирами, які ввів користувач. Результат показує можливе місце: близькість об’єктів сама по собі не підтверджує, що їх видно з однієї точки або що фото зроблено саме там.

## Дані та перевірки

Джерело орієнтирів — [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Під час пошуку застосунок читає локальний CSV. `prepare_data.py` завантажує та готує дані через Overpass API, а `data/source.json` описує вибірку.

Перевірки пошуку можна запустити з папки репозиторію:

```bash
python checks.py
```

Сценарії для демонстрації описані в [demo.md](demo.md).
